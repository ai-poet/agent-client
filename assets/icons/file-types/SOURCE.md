# Material file icons

This directory contains a selected subset of the [Material Icon Theme](https://github.com/PKief/vscode-material-icon-theme) file icons. The project is distributed under the MIT license; see its [upstream license](https://github.com/PKief/vscode-material-icon-theme/blob/main/LICENSE).

Only icons referenced by Waku's file-extension mapping are included so the app does not ship the full icon catalog.
