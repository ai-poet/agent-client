# Changes

## 0.2.3

- 縮短測試名稱，保持斷言不變
- 修正正式 SDK 歷史記錄測試資料，並驗證設定的目標限制

## 0.2.2

- 狀態徽章在圖示後顯示狀態和用時，暫停後顯示原因，不再重複「目標」二字
- 面板只有「暫停」或「繼續」以及「結束」。移除「編輯」：用 `/goal <新內容>` 取代目標。「清除」改為「結束」（`/goal end`），已結束的目標在歷史中顯示為「已結束」
- 目標輪次失敗時只通知一次，由應用程式自身的通知發出；目標仍顯示「已暫停 · 出錯」

## 0.2.1

- 無法再被喚醒的目標不再停在「等待中」或「執行中」：所等待的背景工作被停止後顯示已暫停（已停止），結果因輪次上限被保留時顯示已達輪次上限，最後一輪在重新啟動前結束時顯示應用程式已重新啟動

## 0.2.0

- `/goal <文字>` 立即開始，並透過自動輪次持續執行直到目標完成；中途的訊息或暫停仍屬於該目標
- 完成需先提交依據，再由獨立的「核驗目標」輪次確認；可重新開啟
- 停止後暫停，回覆即繼續；手動暫停需按繼續；重新啟動、分叉、回退或計畫模式會暫停並顯示原因
- 上限：預設 25 個自動輪次，可選 Token 預算與時間上限，以及無進展規則；達到上限時收尾並暫停
- 工具由六個減為三個；編輯、取代和清除僅由你操作
