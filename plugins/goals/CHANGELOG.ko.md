# Changes

## 0.2.3

- 검증 내용을 변경하지 않고 테스트 이름 단축
- 실제 SDK 기록 테스트 데이터를 수정하고 설정된 목표 제한 검증

## 0.2.2

- 상태 배지는 아이콘 뒤에 상태와 시간(일시 중지 후에는 이유)을 표시하며 '목표'라는 단어를 반복하지 않습니다
- 패널에는 일시 중지 또는 재개와 종료만 있습니다. 편집은 제거되었으며 `/goal <새 내용>`으로 목표를 교체합니다. 지우기는 종료(`/goal end`)로 바뀌었고 종료한 목표는 기록에 종료됨으로 표시됩니다
- 목표 턴이 실패하면 앱 자체 알림으로 한 번만 알립니다. 목표에는 계속 '일시 중지됨 · 오류'가 표시됩니다

## 0.2.1

- 다시 깨울 수 없는 목표가 더 이상 대기 중이나 실행 중으로 남지 않고 일시 중지로 표시됩니다(기다리던 백그라운드 작업 중지, 턴 한도에서 보류된 결과, 재시작 전에 끝난 마지막 턴)

## 0.2.0

- `/goal <텍스트>`는 즉시 시작하며 목표가 완료될 때까지 자동 턴으로 계속합니다. 중간의 메시지나 일시중지도 목표에 포함됩니다
- 완료는 근거와 함께 신고한 뒤 별도의 '목표 검증' 턴에서 확인해야 합니다. 다시 열어 취소할 수 있습니다
- 중지하면 일시중지되고 답장하면 재개됩니다. 직접 일시중지하면 재개할 때까지 유지됩니다. 재시작, 포크, 되돌리기, 계획 모드에서는 이유와 함께 일시중지됩니다
- 한도: 기본 자동 25턴, 선택적 토큰 예산과 시간 한도, 진행 없음 규칙. 한도에 도달하면 마무리하고 일시중지합니다
- 도구가 6개에서 3개로 줄었습니다. 편집, 교체, 지우기는 사용자만 할 수 있습니다
