# Changes

## 0.1.20

- 공용 모델 선택기로 검색 모델 선택

## 0.1.19

- 서비스 테스트 중 재시도 표시줄을 제거하고 테스트 실패 후에도 설정을 사용할 수 있도록 수정

## 0.1.18

- 제공업체 컬러 로고와 TinyFish 및 모델 검색 아이콘 표시

## 0.1.17

- 탐색 및 도구 아이콘을 선형으로 복원

## 0.1.16

- 플러그인 아이콘 변경

## 0.1.15

서비스 행의 핸들을 끌어 순서를 바꿉니다. 키보드로도 이동할 수 있습니다. 행은 표준 설정 레이아웃을 사용하고 서비스 로고를 표시하며, 더보기는 아이콘 버튼입니다.

## 0.1.14

각 서비스 행에 위로·아래로 이동을 표시하고, 설정과 테스트는 더보기 메뉴로 옮겼습니다.

## 0.1.13

키를 비우고 저장하면 삭제됩니다. 서비스 목록을 간결하게 하고 순서 변경은 각 행의 메뉴로 옮겼습니다.

## 0.1.12

자동 검색은 모델이 검색을 수행하지 않은 경우를 포함해 실패한 서비스 다음의 활성 서비스를 시도합니다.

## 0.1.11

위아래 버튼으로 검색 서비스 순서를 변경할 수 있습니다. 자동 검색은 모델 검색을 포함한 활성 서비스 순서를 따르며 미지원 시 다음 서비스를 시도합니다.

## 0.1.10

- 모델 검색에서 지원하지 않는 Copilot 계정 제외

## 0.1.9

- 기간 및 도메인 필터 추가
- 검색 서비스 설정 및 동적 페이지 가져오기 대체 경로 추가
- 최근 검색 캐시 및 서비스 할당량 유형 표시
- 설정된 모델 서비스를 직접 선택하는 검색 추가

## 0.1.7

- 양식 레이블과 컨트롤 사이 간격 확대

## 0.1.4

- 마켓 분류와 아이콘 색상 추가
- 도구 이름 번역 추가
- 스킬 이름 번역 추가
