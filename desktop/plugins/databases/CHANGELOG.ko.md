# Changes

## 0.1.23

- 기본 키를 조회하는 동안 처리 중 상태를 유지하여 다른 쿼리가 요청이나 결과를 덮어쓰지 않도록 수정했습니다.

## 0.1.22

- 검증 내용을 변경하지 않고 테스트 이름 단축

## 0.1.21

- 실행 기록을 결과와 같은 표로 표시하고 두 번 클릭하거나 Enter로 SQL에서 열기

## 0.1.20

- SQL을 줄 번호와 구문 강조가 있는 편집기에서 작성하고 ⌘↵로 실행하며, 대화 상자 하단에 취소와 실행 배치

## 0.1.19

- 결과 표의 테두리를 없애고 하단에 행 수를 표시하며, 새 쿼리는 대화 상자에서 SQL을 입력하고, 카탈로그에 데이터베이스와 테이블 아이콘 표시

## 0.1.18

- 카탈로그 새로 고침을 작업 공간 헤더로 이동
- 쿼리 결과에 교차 행과 현지화된 빈 상태 표시
- SQL 기록 열을 정렬하고 선택, 키보드 탐색 및 컨텍스트 메뉴 유지

## 0.1.17

- 탐색 및 도구 아이콘을 선형으로 복원

## 0.1.16

- 플러그인 아이콘 변경

## 0.1.12

- 양식 레이블과 컨트롤 사이 간격 확대

## 0.1.8

- 마켓 분류와 아이콘 색상 추가
- 도구 이름 번역 추가
