# Changes

## 0.1.23

- 主キーの取得中は処理中の状態を維持し、別のクエリによるリクエストや結果の上書きを防止。

## 0.1.22

- アサーションを変更せずにテスト名を短縮

## 0.1.21

- 実行履歴を結果と同じテーブルで表示し、ダブルクリックまたは Enter で SQL に開く

## 0.1.20

- SQL を行番号と構文ハイライト付きのエディタで書き、⌘↵ で実行、ダイアログ下部にキャンセルと実行を配置

## 0.1.19

- 結果テーブルの枠をなくして下部に行数を表示し、新規クエリはダイアログで SQL を入力、カタログにデータベースとテーブルのアイコンを表示

## 0.1.18

- カタログの更新をワークスペースのヘッダーに移動
- クエリ結果に縞模様とローカライズされた空状態を表示
- SQL 履歴の列を揃え、選択、キーボード操作、コンテキストメニューを維持

## 0.1.17

- ナビゲーションとツールのアイコンを線画に戻す

## 0.1.16

- プラグインのアイコンを変更

## 0.1.12

- フォームのラベルと入力欄の間隔を拡大
