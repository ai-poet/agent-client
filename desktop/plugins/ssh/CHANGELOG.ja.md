# Changes

## 0.1.29

- リモートファイルのヘッダーを整理：空白部分のクリックでパスを編集し、入力欄から離れると取り消し

## 0.1.28

- 主な SSH 接続を既定の接続として扱い、ほかの保存済み接続の使用、作成、編集にも対応

## 0.1.27

- リモートファイルパネルにパス、編集、更新を備えたヘッダーを追加し、読み込み中・空のフォルダー・読み込み失敗をパネル内に表示

## 0.1.26

- クリックでリモートファイルを選択し、ダブルクリックでプレビュー

## 0.1.25

- リモートファイルをクリックしてプレビューで開く

## 0.1.24

- リモートパスをプレーンテキストで表示し、空のフォルダーはプレースホルダー行なしで開く

## 0.1.23

- リモートファイルをファイルパッケージと同じファイル・フォルダーアイコンで表示

## 0.1.22

- キャッシュとページ分割を備えた展開可能なディレクトリツリーでリモートファイルを表示
- パンくずで移動するかリモートパスを直接編集
- ファイルメニュー、複数選択、システムからのアップロード、転送時の置換操作を維持

## 0.1.20

- ナビゲーションとツールのアイコンを線画に戻す

## 0.1.19

- プラグインのアイコンを変更

## 0.1.13

- フォームのラベルと入力欄の間隔を拡大
- 初期データの読み込み中も通常のページを保持

## 0.1.8

- マーケットのカテゴリとアイコンカラーを追加
- ツール名の翻訳を追加
