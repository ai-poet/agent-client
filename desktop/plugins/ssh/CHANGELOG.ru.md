# Changes

## 0.1.29

- Заголовок удалённых файлов упрощён: щелчок по пустому месту открывает правку пути, уход из поля отменяет её

## 0.1.28

- Использовать основной SSH-хост по умолчанию и разрешить работу с другими сохранёнными подключениями, их создание и изменение

## 0.1.27

- Панель удалённых файлов получает заголовок с путём, правкой и обновлением, а загрузка, пустые папки и ошибки чтения показываются в панели

## 0.1.26

- Выбирать удалённый файл щелчком и открывать предпросмотр двойным щелчком

## 0.1.25

- Открывать удалённый файл в предпросмотре по щелчку

## 0.1.24

- Показывать удалённый путь текстом и открывать пустые папки без строки-заполнителя

## 0.1.23

- Показывать удалённые файлы со значками файлов и папок, как в пакете «Файлы»

## 0.1.22

- Просмотр удалённых файлов в раскрываемом дереве каталогов с кэшем и постраничной загрузкой
- Переход по цепочке пути или прямое редактирование удалённого пути
- Сохранены меню файлов, множественный выбор, загрузка системных файлов и замена при передаче

## 0.1.20

- Возвращены контурные значки в навигации и инструментах

## 0.1.19

- Новый значок плагина

- Сохранять обычную страницу при загрузке исходных данных

## 0.1.8

- Добавлены категория каталога и цвет значка
