# Changes

## 0.1.29

- 원격 파일 헤더 정리: 빈 곳을 클릭하면 경로를 편집하고, 입력란을 벗어나면 취소

## 0.1.28

- 기본 SSH 호스트를 유지하면서 다른 저장된 연결의 사용, 생성 및 편집 지원

## 0.1.27

- 원격 파일 패널에 경로, 편집, 새로 고침이 있는 헤더를 추가하고 로딩, 빈 폴더, 읽기 실패를 패널에 표시

## 0.1.26

- 클릭하면 원격 파일을 선택하고 두 번 클릭하면 미리보기

## 0.1.25

- 원격 파일을 클릭하면 미리보기로 열기

## 0.1.24

- 원격 경로를 일반 텍스트로 표시하고 빈 폴더는 자리 표시 행 없이 열기

## 0.1.23

- 원격 파일을 파일 패키지와 같은 파일·폴더 아이콘으로 표시

## 0.1.22

- 캐시와 페이지 나누기를 지원하는 확장 가능한 디렉터리 트리로 원격 파일 탐색
- 경로 탐색 표시줄로 이동하거나 원격 경로를 직접 편집
- 파일 메뉴, 다중 선택, 시스템 파일 업로드와 전송 교체 작업 유지

## 0.1.20

- 탐색 및 도구 아이콘을 선형으로 복원

## 0.1.19

- 플러그인 아이콘 변경

## 0.1.13

- 양식 레이블과 컨트롤 사이 간격 확대
- 초기 데이터를 불러오는 동안 일반 페이지 유지

## 0.1.8

- 마켓 분류와 아이콘 색상 추가
- 도구 이름 번역 추가
